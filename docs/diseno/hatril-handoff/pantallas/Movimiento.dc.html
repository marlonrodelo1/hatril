Movimiento

Solo CSS y SVG. El atril del splash es el mismo elemento que abre la presentación: no hay corte.

Del splash a la primera pantalla

0 ms Splash. Atril de 112 px centrado; se dibuja trazo a trazo (900 ms) y queda quieto.
2.500 El atril sube y se reduce a 52 px hasta su sitio en la pantalla 1 (450 ms, salida suave).
+420 Las tarjetas del muro salen «del libro»: suben 18 px y aparecen, escalonadas cada 120 ms (460 ms cada una).
+200 Título y texto, solo opacidad (400 ms). «Saltar» y el botón están desde el principio.
Paso Entre pantallas: el texto sigue al dedo; al soltar, 360 ms. La ilustración saliente se funde (200 ms) y la nueva entra escalonada.
--dur-corta: 200ms; --dur-media: 360ms; --dur-larga: 460ms; --escalon: 120ms; --ease-salida: cubic-bezier(.2,.8,.2,1); --ease-trazo: cubic-bezier(.4,0,.2,1);

Con «reducir movimiento»

Mismo contenido y mismo orden. Nada se desplaza ni se dibuja: todo aparece ya en su sitio.

Cómo se implementa

Los keyframes solo definen el estado inicial («from»). Sin animación, cada elemento ya está en su estado final.

path { stroke-dasharray: 1; } /* pathLength="1" */ @keyframes trazo { from { stroke-dashoffset: 1 } } @keyframes subir { from { opacity: 0; translate: 0 18px } } @media (prefers-reduced-motion: reduce) { .anim { animation: none } .pagina { transition: opacity 150ms } }
